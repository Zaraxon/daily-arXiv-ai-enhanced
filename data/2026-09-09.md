Result: 证明了一致的擦除公理可扩展到含恒等类型的系统而不破坏规范性。商类型可以通过擦除公理安全支持。没有商类型和公理时，利用擦除恒等证明进行传输是安全的；存在商类型及可由等式反射实现的擦除公理时仍然安全。但不受限制的此类传输与擦除的公理化单价性不兼容，[]-cong提供了一种可行的受限替代方案。

Conclusion: 擦除机制能够在较丰富的类型论扩展中保留程序计算正确性，但擦除恒等证明的传输必须受到严格限制，尤其是在与商类型、后设公理和单价性结合时。相关理论结果已由机器检验的Agda证明支持。

Abstract: This text is concerned with the question of whether, in type theory with erasure annotations, one can postulate that some type is inhabited and still have a guarantee that a program will not get stuck. Previous work has provided such guarantees for consistent erased postulates, i.e. postulates that are restricted to be used in erased contexts. Here those guarantees are extended to type theory with identity types.
  Similar ideas provide a simple way to support quotient types: it is shown that one can let things like "the equivalence classes for two related values are equal" be erased postulates and have an eliminator that only computes for the equivalence class constructor, and still get a guarantee that programs will compute correctly.
  Another question is whether programs compute correctly if one is allowed to transport (cast) using erased identity proofs. It is shown that this is safe in the absence of quotients and postulates, and in the presence of quotients and erased postulates that can be implemented using equality reflection. However, unrestricted transports of this kind are not compatible with erased, postulated univalence. For that reason the text includes a study of the function []-cong, which encapsulates a limited form of transport for erased identity proofs.
  The text is accompanied by machine-checked Agda proofs.
